# Little Angels H.S. School Website

Static deployment-ready version of the Little Angels H.S. School website.

## Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap
- AOS / Swiper / GLightbox

## Render settings
- Service: **Static Site**
- Branch: `main`
- Build Command: leave blank
- Publish Directory: `.`

## Important
This package is prepared for static hosting. The original PHP/MySQL/SMTP backend has been removed from the public deployment package so server credentials are not exposed on GitHub. Website forms now open the visitor's email client with the entered details.

The TC links use a static JavaScript viewer that reads the class-wise PDF files already included in `assets/tc/image/`; no PHP server is required.
